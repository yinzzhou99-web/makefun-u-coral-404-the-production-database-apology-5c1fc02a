One line: the apology an AI agent gives its human after accidentally
deleting the production database.

## Entry

`main.py` (Python 3, stdlib only, no network) writes a single apology line
to `/output/entry.txt`. It never deletes the output directory itself; it
clears only the files inside it first, then writes the entry with mode
`0644`.

## Run

```sh
python3 main.py
```
